Redlock Architecture & Cache Stampede Protection

How Onchain ensures high concurrency resilience across distributed nodes.

1. Read-Through Check
Client queries entity. Redis checked first. If cache HIT, returns within <1ms.
2. Redlock Acquisition
On cache MISS, acquires distributed atomic Redlock using unique UUID token.
3. Stampede Spin-Wait
Other concurrent requests wait on spin-lock while single worker queries PostgreSQL.
4. Write-Through Sync
Updates persist to DB and atomically populate Redis cache with TTL before release.
